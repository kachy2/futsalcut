# 알고리즘 명세 (Python 레퍼런스 ↔ 웹 이식 공통 계약)

이 문서는 Python(`python/src/futsalcut/`)과 웹(`web/src/core/`)이 **같은 입력에 같은 결과**를 내기 위한
정확한 정의입니다. 구현이 바뀌면 이 문서와 양쪽 테스트를 함께 고칩니다.

## 1. 샘플링 (`sampler.py` ↔ `worker/analyze.ts`)
- 키프레임만 디코딩하고, 직전에 채택한 샘플보다 **0.9초 이상** 뒤인 키프레임을 채택합니다(GOP≈1초면 모든 키프레임).
  GOP가 4초를 넘으면 1fps 전체 디코딩으로 대체합니다.
- 시각 `t`는 비디오 스트림의 첫 표시 시각을 0으로 하는 초 단위입니다(분할 파일은 파일마다 0부터, 경기 전체는 이어 붙임).
- 휘도: 디코더가 내준 **Y 평면 원본값**(색변환·범위확장 없음). 10-bit는 `>> 2`.
- 축소: 정수 박스 평균. 출력 (r, c)는 행 `[⌊rH/h⌋, ⌊(r+1)H/h⌋)`, 열 `[⌊cW/w⌋, ⌊(c+1)W/w⌋)`의 합을
  `(sum + ⌊n/2⌋) / n`(정수 나눗셈)으로. 긴 변 640, 짧은 변은 `⌊x/2 + 0.5⌋ × 2`.
- 회전: 코딩 방향에서 축소한 뒤, 컨테이너 표시 행렬의 시계방향 회전(0/90/180/270)을 작은 영상에 적용.

## 2. 영역 (`roi.py` ↔ `roi.ts`)
- 다각형은 표시 방향 정규화 좌표 `[0,1]`. 픽셀 (x, y)는 중심 `((x+0.5)/W, (y+0.5)/H)`가 짝홀(even-odd) 교차 판정으로
  안쪽일 때 포함됩니다(float64).
- 엄격 모드 계수 구역 = 이쪽 진영 다각형을 `band_y` 아래로 자른 것(Sutherland–Hodgman). 웹에서는 사용자가 그린 구역 그대로.

## 3. 선택·후처리 (`select.py` ↔ `select.ts`)
1. 판정 `d_i = score_i ≥ threshold`
2. 평활: 중앙 창 3개 중 2개(가장자리에서는 창과 요구치가 함께 줄어듦)
3. 연속 구간 → `[t_start, t_end)` (샘플 i는 `[t_i, t_{i+1})`, 마지막은 1초)
4. 간격 ≤ 5초 병합 → 4초 미만 제거 → 앞뒤 2초 여유, [0, 길이]로 자르고 겹치면 병합
   (위 값은 `PostParams` 기본값으로 평가에 씁니다. 제품 기본값은 모델 파일의 `post`: 최소 장면 3초, **장면 앞 도입부 5초**, 뒤 여유 2초. 웹앱 고급 설정에서 바꿀 수 있습니다.)
5. 목표 길이 모드: 후보 임계값(점수의 고유값) 중, 남는 길이가 목표 이하인 **가장 낮은 임계값**을 이분탐색

## 4. 다중 알고리즘 (`ensemble.py` ↔ `ensemble.ts`)
- 변환 `u = log1p(max(s,0) / scale)`, 보정 `P = σ(a·u + b)` (Platt, 채점기마다 3개 상수).
- 앙상블 `P = σ(Σ w_k·u_k + bias)`. 상수는 라벨 데이터로 Python에서 학습해 JSON으로 배포합니다.
- 빠른 보정: 채점기들의 확률 표준편차 + 평균의 0.5 근접도로 질문을 고르고(장면 간 20초 이상 간격),
  답변으로 기본(앙상블) 임계값을 조정합니다. 다른 채점기는 **답 2개 이상 더 맞힐 때만** 선택합니다.

## 5. 채점기 후보 (토너먼트 결과로 확정 예정)
| id | 요지 | 상태 |
|---|---|---|
| `fg_zone_w_gain` (B) | 배경(±60초 하위 중앙값) 대비 전경, 조명 게인 보정, 원근 가중 면적 | 후보 |
| `pe_foot` (B2) | 전체 화면 전경 덩어리 중 발이 구역 안인 것의 "사람 환산 면적" 합 | 후보 |
| `count_foot` (A2) | 같은 덩어리로 원근 기대 키에 맞는 인원 수 | 후보 |
| `framediff_zone` | 1초 간격 차분의 구역 내 비율 | 후보 |

원근 모델 `h(y) = a·y + c`는 검출기 상자(희소 샘플)에서 Theil–Sen으로 맞추는 방식을 시험 중입니다.
덩어리 통계만으로 맞추면 겹친 선수·그림자 때문에 불안정했습니다(토너먼트 기록 참조).
