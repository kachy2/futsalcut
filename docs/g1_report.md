# 게이트 G1 보고서

대상: 검증 영상 video_1 (비공개 촬영본, Galaxy 4K, 11.9분). 정답 = 엄격 기준(가까운 구역에 2명 이상) 52초 / 714초, 에피소드 8개.
수치는 2분 블록 교차검증입니다(앙상블 가중치는 남겨 둔 블록에서 평가). **영상이 1개뿐이라 잠정치**이며, P4(다른 영상)에서 다시 검증합니다.
운영점(임계값·최소 장면 길이)은 이 영상에서 골랐으므로 낙관적일 수 있습니다.

## 1. 결론
- **품질 기준 통과(잠정)**: 권장 자동 설정(경량 앙상블, 확률 임계 0.3, 최소 장면 3초)
  - 편집 정밀도 0.93, 재현율 0.98, 3초 이상 에피소드 7/7 포함(1초짜리 1개만 누락), 가짜 장면 0
  - 12분 → **75.1초(4개 장면, 10.5%)**. 실제 무손실 결과: 452MB, 디코딩 오류 0, 컷 지점 A/V 오차 최대 7.1ms, 합치기 2.4초
- **제안 코드 아이디어·기존 도구보다 확실히 우수**: 교차검증 F1 0.86~0.88 vs 제안 아이디어 0.14~0.70, DVR-Scan 0.58~0.72
- **다중 알고리즘 효과 확인**: 앙상블 ≥ 단일 최고, 검출기는 애매한 샘플 약 5%에만 써도 같은 성능

## 4. 결정이 필요한 사항
1. **판정 기준**: 엄격(가까운 구역만, 권장) vs 진영(하프라인 부근 포함) (비교 이미지는 실제 선수가 나오므로 저장소에 넣지 않았습니다).
   웹앱에서는 사용자가 그리는 구역으로 정해지므로, 여기서 정하는 것은 **안내 문구와 기본 구역 모양**입니다.
2. **기본 운영점**: 재현율 우선(임계 0.3, 권장) vs 정밀도 우선(0.5, 이 영상에서 에피소드 3개 누락).
3. **다음 단계**: P5(웹앱 MVP) 진행, P4용 다른 영상 제공 시점, 호스트 디스크 증설.
