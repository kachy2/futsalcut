# 정답(GT) 라벨링 규칙 v1

평가용 정답은 **GOP(키프레임) 1장 = 1초 단위**로 붙입니다. 라벨은 알고리즘 결과를 보기 **전에** 작성하고,
규칙이 바뀌면 버전을 올립니다.

## 영역 정의
- **이쪽 진영(near half)**: 카메라가 비추는 쪽 골라인부터 하프라인까지의 경기장 바닥. 영상마다 다각형으로 정의하고
  `eval/labels/<영상>.roi.json`의 `near`에 저장합니다(정규화 좌표).
- **하프라인 띠(midfield band)**: 이쪽 진영 중 하프라인에 붙은 먼 띠. 선수가 작게 보이는 구역입니다.
  같은 파일의 `band_y`(정규화 y)보다 위쪽입니다.
- 선수의 위치는 **발(가장 낮은 점)** 기준입니다. 발이 다각형 안이면 이쪽 진영으로 셉니다.
- 경기장 밖(골라인 뒤, 터치라인 밖, 펜스 뒤, 예비 골대 주변)의 사람은 세지 않습니다.
  단, **공을 다루다 터치라인을 잠깐 넘은 선수**(볼 경합, 아웃 직전 볼 쫓기)는 플레이 중이므로 안쪽으로 셉니다.
  → 알고리즘용 ROI는 터치라인 바깥으로 약간 여유를 두는 것이 좋습니다(사용자 안내 문구에 반영).

## 라벨 값
| 라벨 | 의미 | 엄격 기준 | 진영 기준 |
|---|---|---|---|
| `2` | 이쪽 진영의 **띠 아래(가까운 구역)에 선수 2명 이상**, 플레이 중(이동·볼 경합·공수 전개) | 남김 | 남김 |
| `M` | 이쪽 진영에 2명 이상이지만, 띠 아래에는 2명 미만(하프라인 부근 플레이) | 제거 | 남김 |
| `1` | 이쪽 진영에 선수 **1명**(홀로 선 수비수·골키퍼, 공을 쫓는 1명 등) | 제거 | 제거 |
| `F` | 선수가 **먼 쪽(하프라인 너머)에만** 보임 | 제거 | 제거 |
| `0` | 경기장에 선수 없음(경기장 밖 사람만 있는 경우 포함) | 제거 | 제거 |
| `b` | 띠 아래 2명 미만은 확실하지만, 띠 안 인원(진영 안/밖)이 작아서 불확실 | 제거 | 채점 제외 |
| `?` | 판정 보류: 경계를 걸친 선수, 심한 가림·흐림, 2명 이상이 서 있기만 하는 정지 상황(킥 준비·휴식 등) | 채점 제외 | 채점 제외 |

- **엄격 기준**은 "카메라 앞 가까운 플레이만", **진영 기준**은 "하프라인까지의 이쪽 진영 전체"입니다.
  둘 다 평가하고, 기본값은 G1 보고 때 사용자가 예시 장면을 보고 정합니다.

- 골키퍼도 선수로 셉니다. 따라서 골키퍼 + 다른 선수 1명이 이쪽 진영에서 플레이하면 `2`입니다.
- 전이 구간(그 1초 안에 선수가 경계를 넘나드는 경우)은 화면 기준으로 판단하고, 애매하면 `?`.
- `?`는 전체의 10% 이하로 유지합니다. 넘으면 규칙을 다듬습니다.

## 절차와 품질 관리
1. 1초 키프레임 캐시에서 컨택트 시트를 만듭니다. 이쪽 진영을 잘라 다각형을 겹쳐 그리고 시각을 표시합니다(4x4 타일).
2. 시트를 보며 라벨을 기록합니다. → `eval/labels/<영상>.labels.json`
3. 무작위로 섞은 15%를 다시 블라인드로 라벨링해 일치도(Cohen κ)를 보고합니다.
4. 애매한 샘플(약 40장)은 사용자 검토용으로 따로 모읍니다(선택 사항).
