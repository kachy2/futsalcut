# 풋살컷 (FutsalCut) — 고정 카메라 풋살·축구 영상에서 플레이 장면만 자동으로

[English](README.md) · **웹앱: https://kachy2.github.io/futsalcut/?lang=ko**

삼각대에 폰을 세워 찍은 풋살·축구 영상(1~2시간, 4K)에서 **카메라 쪽 구역에 선수 2명 이상이 있는 장면만** 골라
**원본 화질·음성 그대로(재인코딩 없이)** 하나의 MP4로 합쳐 주는 무료 오픈소스 도구입니다.

- **설치 없음**: 웹 브라우저(Chrome/Edge PC 권장)에서 바로 실행
- **업로드 없음**: 영상은 기기 밖으로 나가지 않습니다. 분석과 저장 모두 브라우저 안에서 처리
- **빠름**: 키프레임만 분석(초당 1장)하고 패킷을 그대로 복사해 2시간 4K 영상도 수 분 안에 처리
- **조절 가능**: 자동(추천) / 감도 / 목표 길이, 구역 그리기, 고급 설정(장면 앞 도입부 길이·알고리즘 선택·비교·빠른 보정)
- **분할 파일 지원**: 갤럭시처럼 4GB마다 나뉜 파일을 한 경기로 이어서 처리

## 사용법
1. 경기 영상 파일을 선택합니다(분할된 파일은 함께 선택).
2. 첫 화면 위에 **선수 2명 이상이 들어오면 남길 구역**을 그립니다(카메라 쪽 진영, 하프라인 부근 제외 권장).
3. 분석이 끝나면 타임라인에서 남길 장면을 확인하고 필요하면 감도나 목표 길이를 조절합니다.
4. **MP4로 저장**을 누르면 원본 화질 그대로 저장됩니다.

## 동작 원리
1. 키프레임(보통 1초 간격)만 디코딩해 640px 휘도 영상으로 줄입니다(WebCodecs 하드웨어 디코딩).
2. ±60초 시간 중앙값 배경과 비교해 구역 안의 움직이는 사람(전경)을 찾고, 원근을 보정한 "사람 환산 면적"과 인원을 계산합니다.
3. 여러 채점기를 보정·결합한 앙상블이 장면마다 확률을 내고, 애매한 장면에만 사람 검출기(D-FINE-N, Apache-2.0)를 씁니다.
4. 짧은 끊김을 병합하고, 장면 앞에 도입부(기본 5초: 공격이 전개되는 과정)와 뒤 여유(2초)를 붙여 키프레임 경계에 맞춘 뒤,
   압축된 패킷을 그대로 복사해 합칩니다.

평가 방법과 결과는 [docs/g1_report.md](docs/g1_report.md), 알고리즘 명세는 [docs/algorithms.md](docs/algorithms.md)를 보세요.

## 지원 환경
| 환경 | 상태 |
|---|---|
| Chrome / Edge (Windows·Mac PC) | 권장. H.264 지원, HEVC는 GPU·확장에 따라 다름 |
| Safari 26+ (Mac) | 분석 가능, 큰 파일 저장은 추후 지원 |
| Firefox | H.264만 분석 가능, 큰 파일 저장은 추후 지원 |
| 모바일 | 실험적 |

## 개발자용
- `web/`: Svelte 5 + Vite 웹앱(분석·내보내기 워커, Python과 같은 결과를 내는 TypeScript 코어)
- `python/`: 레퍼런스 구현(샘플러, 특징, 앙상블, 무손실 리먹서) — Docker `futsalcut-py` 이미지
- `eval/`: 평가 지표, 토너먼트(알고리즘 비교), 기준선(기존 도구·AI 제안 코드) 비교 — 원본 영상·정답 라벨·제안 코드 자체는 비공개
- 테스트: `npm test`(Vitest: Python과의 비트 단위 일치 포함), `npx playwright test`(헤드리스 Chrome e2e)
